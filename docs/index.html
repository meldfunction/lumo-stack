Why Lumo

An AI that minds its own business

Lumo is Proton's assistant. Same folks who do encrypted Mail and VPN, same allergy to snooping.

Confidential

Chats are encrypted, Proton keeps no logs of them, and they don't train anyone's model.

Open

Open-source models. Proton's Lumo web and mobile apps are open source too (GPLv3), so you can check the receipts.

Swiss, one account

Run by Proton in Switzerland, on the account you already use for Mail, Drive and VPN. Free tier, zero ads.

Straight talk: for heavy coding and long tool chains, Claude, GPT and Gemini models are still stronger. Lumo wins when where your words end up matters more than raw horsepower.

Three ways in

Keep the terminal workflow, swap the model. The launcher checks that every route leads to Lumo before it lets Claude Code start.

Browser

Chat in Open WebUI, plus Lumo Home: status, one-click Proton sign-in, and drag-and-drop files in and out.

Claude Code, minus Anthropic

Same terminal. Different brain.

Love the Claude Code workflow but want Lumo doing the thinking? claude-lumo swaps the brain and keeps Anthropic out of the loop. Here's exactly how:

Claude Code normallyclaude-lumo instead
PromptsGo to Anthropic's APIGo to LiteLLM on 127.0.0.1:4000, which only forwards to Lumo
Sign-inAnthropic account or API keyYour local LiteLLM key; ANTHROPIC_API_KEY is unset
ModelsOpus, Sonnet, HaikuEvery slot, subagents included, maps to lumo, lumo-max or lumo-lite
Background trafficTelemetry, error reports, update checksAll switched off
MCP serversLoaded, each making its own connectionsOff by default (LUMO_KEEP_MCP=1 brings them back)
Config driftTrustedRefuses to start if LiteLLM routes anywhere but Lumo

We checked by watching the network: with MCP off, a claude-lumo session's only connection was to 127.0.0.1:4000. Your plain claude stays your normal Claude Code. Don't have Claude Code yet? The installer fetches it for you (one download from Anthropic, no account needed for claude-lumo). Heads up: claude-lumo runs on your Mac with Claude Code's normal permission prompts, not in the jail, so use lumo for anything that edits files.

Under the hood

One road in, one road out

Open WebUIlocalhost:8080

lumo-bridge127.0.0.1:3003 · login encrypted

Every launcher reads the router config before it starts. If a route points anywhere other than Lumo, it refuses to run. Everything listens on 127.0.0.1, so nothing's open to your network.

The jail

An agent that can't wander off

AI agents run commands. Ours runs them in a box with no windows.

  • No internet. Its only road leads to Lumo.
  • No root, no sudo, no Linux capabilities, read-only system.
  • Can't see your home folder, your keys or the rest of your machine.
  • Can't edit its own rules: the config lives outside the jail.
  • Sees your workspace: code/ read-write, inbox/ read-only, out/ for results.
  • A git snapshot before every session. lumo restore rewinds, and the rewind is undoable too.

Click your way through

  1. Download the zip and unzip it.
  2. Double-click Install Lumo.command. First time, macOS gets suspicious: right-click it and choose Open.
  3. Pick a home for Lumo's files (or keep ~/lumo), and say yes or no to Claude Code.
  4. Sign in to Proton in the browser window that pops up. It closes itself when you're done.
  5. Lumo Home opens. You're in.

Or the terminal way

  1. Clone and install: 
    git clone https://github.com/meldfunction/lumo-stack.git ~/lumo-stack
cd ~/lumo-stack && ./install
  2. Commitment issues? Preview everything first: 
    ./install --dry-run
  3. Options: --workspace DIR, --with-claude, --no-login.

The first install pulls a few GB (Open WebUI, LiteLLM, OpenCode) and takes 10–20 minutes. Make a coffee. It finishes with the Proton sign-in and a lumo doctor run. Re-running is safe; your keys, settings and login stay put. Changed your mind? ./uninstall removes it all and keeps your files; add --purge to take those too.

Fine print, in big print

What to expect

Tool calling is experimental

Quick edits and file writes work. Long, many-step coding sessions trip over themselves more than with Claude or GPT.

Some Lumo perks stay home

Lumo's web search, image generation and memory don't make it through the bridge.

Your login babysits itself

It lasts 24 hours and renews on its own. If Proton signs you out, Lumo Home and a desktop notification tell you.
