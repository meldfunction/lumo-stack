Lumo Stack

A private way into Proton Lumo from Claude Code, from a locked-down coding assistant, and from your browser. It runs on your own machine, with no Anthropic or OpenAI account.

macOS available now Windows · v0.2 Linux · v0.2

Unofficial. Lumo has no public API yet. Lumo Stack uses lumo-tamer, a community bridge that talks to Lumo the way Proton's web app does. Proton could block it, and it could put your Proton account at risk. Not affiliated with or endorsed by Proton.

Three ways in

Use Lumo where you already work

Each one talks only to Lumo, through a bridge and router that run on your machine and listen on localhost.

Claude Code

claude-lumo

The Claude Code terminal interface with Lumo as the model. No Anthropic subscription or API key; the launcher checks every route points at Lumo before it starts.

Coding assistant

lumo · lumo code-web

OpenCode in a container that can see only your workspace and has no internet. In the terminal or in the browser, with git snapshots so any session can be undone.

Browser

lumo web · lumo home

Chat in Open WebUI, plus Lumo Home: a dashboard for status, one-click Proton sign-in, and moving files in and out of the workspace.

The coding jail

An assistant that can't wander

  • Read-only system, no root, no sudo, no Linux capabilities
  • Internal network with no internet; one relay leads only to Lumo
  • Its own config lives outside the workspace, mounted read-only
  • CPU, memory and process limits
  • A git snapshot before every session; lumo restore rolls back, and the restore can be undone too
  • Browser UI is password-protected, with the password kept in your keychain

Install

Install Lumo Stack

You'll need a Proton account. Proton Unlimited includes free-tier Lumo; the Lumo Plus add-on raises usage limits.

Before you start

macOSOrbStack or Docker DesktopNode.js 20+Python 3.10+gitChrome, Brave or Edge 
brew install git node python
brew install --cask orbstack

With dialogs

  1. Download the Lumo Stack folder.
  2. Double-click Install Lumo.command. The first time, right-click it and choose Open.
  3. Pick where Lumo keeps its files, or use the suggested ~/lumo.
  4. When asked, sign in to Proton in the browser window that opens. It closes by itself.
  5. Lumo Home opens in your browser when everything is ready.

In the terminal

  1. Get the code into ~/lumo-stack and run the installer: 
    cd ~/lumo-stack
./install
  2. Preview first without changing anything: 
    ./install --dry-run
  3. Options: --workspace DIR, --with-claude, --no-login.

The first install downloads a few GB (Open WebUI, LiteLLM, OpenCode) and takes 10–20 minutes. It ends with the Proton sign-in and lumo doctor. Re-running is safe: keys, settings and your login are kept. To remove everything, run ./uninstall; add --purge to also delete your workspace.

Windows and Linux are coming in v0.2

The next release moves the whole stack into Docker Compose, so the same setup runs on every platform with only Docker and a browser installed.

  • Sign in to Proton through a browser container, from any browser
  • The setup wizard runs in Lumo Home, identical on every platform
  • Terminal installers for each platform: install.sh and install.ps1
  • The same jail, the same localhost-only ports, the same lumo doctor checks
Limits

What to expect

Tool calling is experimental

Simple edits and file writes work. Long, many-step coding tasks misfire more than with Claude or GPT models.

Lumo-only features stay in Proton's apps

Web search, image generation and memory don't come through the bridge.

Your Proton login renews itself

It lasts 24 hours and refreshes automatically. If Proton signs you out, Lumo Home and a notification tell you to sign in again.

Built on an unofficial bridge

When Proton ships its official Lumo API, the bridge can be swapped out and the account risk goes away.
